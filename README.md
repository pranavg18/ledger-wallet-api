# Ledger Wallet API

A REST API for digital wallets backed by a tamper-evident, double-entry ledger
(Java 21, Spring Boot, PostgreSQL).

Course project by Team TRAP: Pranav Goyal, Aprajita Agarwal, Rudra Hardik Shroff and
Tanuj Hardikkumar Shah.

The project skeleton, requirements and plan arrive through reviewed pull requests.
